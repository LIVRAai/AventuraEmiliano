LA EXPEDICIÓN DE EMILIANO

Prototipo web educativo responsive para móvil y tablet.

Incluye:
- 3 misiones progresivas de división.
- Interacción táctil.
- Animaciones y sonidos generados por el navegador (sin archivos externos).
- Botón para silenciar.
- Pistas.
- Progreso guardado en el dispositivo con localStorage.
- Diseño adaptable para teléfono y tablet.

Para probar:
1. Abre index.html en Chrome, Safari o Edge.
2. En celular/tablet puede abrirse desde un hosting estático (GitHub Pages, Netlify, Vercel, etc.).

Archivos:
- index.html
- styles.css
- app.js
